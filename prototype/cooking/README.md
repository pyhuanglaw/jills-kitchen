# 料理流程 prototype（proto/cooking-flow）

這是一個獨立的試玩頁，**不是遊戲本體**：不讀存檔、不動正式遊戲的任何系統，只為了試「料理在工作站之間流動」好不好玩。

## 怎麼打開

- 線上：私人的 Artifact 連結（見最新的報告）。
- 本機：用瀏覽器直接打開 `prototype/cooking/index.html`（不需要伺服器）。

## 怎麼玩（第一張單）

1. 第一張單是「黃金蛋炒飯」。點食材冰箱裡的 🍚（或下面 1 號桌單子上的 🍛），再點「炒鍋」。
2. 炒鍋自己會炒：黃色的圈是進度，上面的數字是還剩幾秒。
3. 好了會響一聲、圈變綠。點它，再點下面 1 號桌的盤子（也可以直接拖過去）。
4. 一桌到齊，服務生從出菜口端走。

之後每一晚只多一、兩件新的事：兩站的菜（義大利麵：湯鍋 → 平底鍋）、慢的烤箱、兩樣組起來的漢堡、可以先做起來的布丁、要過三站的披薩，
以及第一位廚師（他把爐台上好了的東西送到下一站）和負責咖啡的沈晴。

## 測試工具

- `bot.js`：照「一個認真的人」的順序玩（一次只做一件事，`react` 秒一個動作），透過頁面上的 `window.__cook` 做跟點擊一樣的動作。
- `playtest.py`：每一晚、幾個 seed、有沒有員工，印出出菜、走掉的桌數、焦掉、品質、每分鐘搬幾次、連續從同一個地方拿的比例、
  平均同時在煮幾樣、員工搬了幾次。

```
python3 prototype/cooking/playtest.py --seeds 3 --nocook --react 1.0
```
