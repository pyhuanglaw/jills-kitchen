## 2. 三項決策怎麼做的（還有做的時候找到的）

**一、一鍵補貨**
- 按下去：先把不在菜單上的菜（跟「退掉不在菜單上的庫存」那顆按鈕同一批）的庫存全部退掉，再照今晚的菜單補；冰箱還是放不下時，沿用
  v2.5.3 的公平分配（沒有菜是 0 份）。只有按這顆按鈕才退；Jill 前兩天自己補貨不退；營業中不退（訂單用掉的份數那時已經不在冰箱裡）。
- 退款＝當初付的錢：遊戲現在記住每道菜的平均進貨價（用掉、放回不改它；供應商多送的、熟客帶來的算 0 元；退款無條件捨去）。舊存檔裡的
  庫存沒有紀錄，照那道菜的一般價錢算。**這也修掉一個舊 bug**：以前退貨照「今天的價錢」，活動日前後退可以多拿錢。
- 「冰箱滿了」：後期建議量本來就剛好塞滿冰箱，前一晚剩下的一兩份就會讓某道菜少 1 份，以前每天早上跳；現在差 1 份或一成以內不跳，
  差更多才跳，並說是哪幾道菜放太多。
- **做的時候找到**：開店前、商店、結算這些整頁畫面開著時跳出的小提示，以前都在畫面底下，玩家看不到（包括 v2.5.3 的「冰箱滿了」）。
  現在畫面開著時提示在畫面上面、「開始營業」上方，停久一點。

**二、故事安排的來店**
- 只保護「為今天到期的那一幕而來的那一次」（`beat`）：怡君的各幕、私人包廂的故事、Sophie 和 Mia 的故事晚上、Ken 和杜、予安、王家陪予安試彈、
  Madame Lin 退休那天和第一次來 Lounge、二樓的故事、晴×阿拓的「今天喝？」。只是讓 Sophie 和 Mia 變熟的來店、Madame Lin 之後偶爾來、包場和
  包廂訂位的客人——照一般客人。
- 那一次：耐心用完繼續等；客滿就晚一點再來，直到晚上快結束；最後還是進不來，門口不叫她的名字，故事改天；冰箱沒有她要的菜也不讓她餓著走。
- 認識怡君以前，遊戲的提示叫她「T? 的客人」。
- **做的時候找到**：重跑原始失敗案例時，怡君等到很晚才吃到，秀琴阿姨在洗碗，還沒走過去怡君就吃完走了，那一幕延到隔天。現在那個人會在
  座位上多坐一下等員工過來（最多 40 秒），那一幕在當晚演出。

**三、同一晚的名字**
- 抽籤照舊（不動當天的亂數）；抽到今晚用過的名字時，換一個沒用過的：同一類的、同一類的備援、大人可以借別類大人的、再來是「鍾先生」
  「鍾先生和太太」「鍾家」這種餐廳叫不認識的客人的叫法（不用遊戲裡已經有人的姓：王 李 林 陳 周 杜 沈 許），最後「另一位 Eric」，全部用完
  才重複。不會一直重抽。
- 熟客、有名字的人、員工、故事和訂位指定的名字不換；訂位的名字開店就算用掉；跟營業中存檔一起存。
- **做的時候找到**：模擬兩輪都還有晚上重名（後期一晚大人加上門口走掉的要 60–80 個名字），所以加了姓氏那一層，又把原本備援裡的「許小姐」
  換掉（許葳是 Lounge 的人）。
