Private Dining Room｜最後一輪空間整理

我看過最新 PDR screenshot。

目前新版已經比上一版好很多：

- 原本左側擋路的小桌移除：正確，請保留
- 中央 vertical stone dining table：正確，請保留
- stone floor：正確，請保留
- deep olive Art Deco architecture：正確，請保留
- 窗邊原本深色木 sideboard 改成淺色／白色石材方向：正確，請保留

這次不要 redesign PDR。

只需要完成最後一個很重要的空間原則：

【PRIVATE DINING ROOM 的兩側走道必須寬敞、乾淨，不要為了填空間一直增加家具。】

━━━━━━━━━━━━━━━━━━
1｜移除右上角新增的高直立展示櫃
━━━━━━━━━━━━━━━━━━

請直接移除目前右上角靠牆的：

tall narrow glass display cabinet / display case

它現在看起來很像 IKEA / furniture showroom 的展示櫃，
與這個 Private Dining Room 的氣質不合。

而且這個房間現在根本不需要再增加一件大型家具。

請：

- 直接移除
- 不要用另一個大型櫃子取代
- 不要改成酒櫃再塞回去
- 不要因為移除後有空位，就覺得必須填滿

那個地方可以空著。

Negative space 是這個房間設計的一部分。

━━━━━━━━━━━━━━━━━━
2｜兩側 circulation 必須保持寬敞
━━━━━━━━━━━━━━━━━━

中央 vertical stone table 已經是整個房間最強的 visual anchor。

因此中央桌兩側應該保留：

- 寬敞的服務走道
- 清楚的 circulation
- 足夠的視覺留白
- 讓服務人員可以自然行走的空間
- 讓 4–10 人使用時仍然不覺得擁擠的尺度感

不要在兩側走道放：

- side table
- display cabinet
- floor decoration
- decorative furniture
- unnecessary shelving
- plant stand
- random storage
- 任何只是為了「畫面不要空」而加入的東西

尤其不要把 free floor area 理解成：

「這裡還可以塞家具。」

這個 PDR 應該有一種：

【桌子很大，但房間比桌子更從容】

的感覺。

而不是：

【桌子很大，所以剩下的地方全部塞滿。】

━━━━━━━━━━━━━━━━━━
3｜需要裝飾時，優先使用 WALL / PERIMETER
━━━━━━━━━━━━━━━━━━

如果覺得房間需要更多 Art Deco detail 或生活感：

優先使用靠牆、牆面或建築本身。

例如可以使用：

- wall sconces
- restrained framed artwork
- Art Deco wall molding / panel detail
- very shallow wall-mounted decoration
- mirror if visually appropriate
- architectural lighting
- curtains / window treatment
- existing plants near perimeter
- existing low sideboard against wall

而不是把東西放到走道。

原則：

【Decoration goes to the wall / perimeter.
Circulation stays open.】

如果某個物件可以靠牆，就不要讓它突出到主要 circulation。

━━━━━━━━━━━━━━━━━━
4｜靠牆家具也要克制
━━━━━━━━━━━━━━━━━━

「靠牆可以」不代表每面牆都要放家具。

目前窗邊的淺色 sideboard 已經可以作為主要 service / storage furniture。

不要再沿著其他牆面排滿：

cabinet + console + display case + shelf + table。

PDR 不是家具展示間。

牆面可以單純依靠：

deep olive Art Deco architecture
+ lighting
+ artwork
+ molding

來完成。

高級感很多時候來自：

比例
+ 材質
+ 光線
+ 留白

而不是家具數量。

━━━━━━━━━━━━━━━━━━
5｜保持目前 Material Language
━━━━━━━━━━━━━━━━━━

目前請繼續維持：

ARCHITECTURE
= deep olive / muted forest green Art Deco walls

FLOOR
= warm gray / charcoal stone

MAIN HERO
= vertical warm ivory / creamy stone dining table

SERVICE FURNITURE
= warm ivory / very pale greige / light stone

ACCENTS
= restrained aged brass + warm lighting

不要重新加入大量：

- dark wood
- walnut
- black furniture
- orange / reddish wood

窗邊現在改成的淺色／白色 stone sideboard 方向是對的。

━━━━━━━━━━━━━━━━━━
6｜不要改動已經成功的部分
━━━━━━━━━━━━━━━━━━

這次只做：

1. 移除右上角 tall display cabinet
2. 確認兩側 walkway / circulation 寬敞
3. 把不必要的 floor-standing decoration 移到牆面／perimeter，或直接刪除
4. 保留適當 negative space

不要：

- 改中央長桌 orientation
- 改 stone floor
- 改座位 capacity
- 改 reservation
- 改 minimum spend
- 改整體 Art Deco direction
- 重新設計整個 PDR
- 為了填空間新增其他大型家具

━━━━━━━━━━━━━━━━━━
7｜最終視覺判斷
━━━━━━━━━━━━━━━━━━

「一張長桌，旁邊擺了很多家具。」
