- **原始失敗**（`original_failure.txt`；完整回歸 80ce485 part 2，單獨重跑一樣）：`30% of the night's profit: {'ken': 3449, 'kt': {'n': 23, 'rev': 16640, 'cost': 5145}, ...}`。

  這一輪改了一些用到亂數的地方（第一批的評論、Dylan 換菜），這一晚的客人點的東西變了。
