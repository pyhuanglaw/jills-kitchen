## 打開遊戲會看到的

- **Dylan**：他想吃的都賣完時，從冰箱裡還有的菜點一份（主菜優先，再來其他菜、甜點、飲料；不點酒、不點 Lounge 的小點）——就是一張
  普通的點單，Jill 不用另外做什麼。什麼都沒有了，他就像平常吃完飯一樣從前門走，日誌寫「今天想吃的都沒了，Dylan 先走了。」——不會
  「想點的都賣完了，走了」、不算賣完的損失、不寫評論。等太久時是「Dylan 等不下去，先走了。」，不會「生氣地離開了」，也不寫評論（他本來
  就從來不寫評論）。揭曉前、揭曉後都一樣，沒有任何一句說他是 Jill 的先生。
  - 查的時候發現：遊戲本來就只讓客人從還有的菜裡點，Dylan 會空手離開，其實是「只剩甜點、他這次又沒想吃甜點」的時候（全新遊戲第 29 天
    那一次）。現在那種情況他會點那份甜點。
- **重要角色**（Madame Lin、Ken、Monsieur 杜，熟客陳伯伯、Mia、小林、Leo、Sophie、王先生、王太太，正式認識以後的怡君，予安）：
  - 坐著等不下去：「陳伯伯 等不下去，先走了。」，他自己說一句（例如「等久了，老人家先回去了。」），一星評論就是那句話。
  - 在門口等不到位子：二星評論是他自己的話（例如 Ken：「沒位子。下次早點。」）。
  - 吃了不滿意：用自己的話講那道菜（例如 Madame Lin：「今天的香煎鴨胸不像妳做的。」）。
  - 想點的都賣完：說自己的話，不說陌生人的「下次早點來。」。
  - 好評裡不會出現只有陌生人才會寫的句子（「比想像中好」「下次帶朋友」「值得繞路」「要把這家店藏起來」……）。
  - **星數、對評分的影響、結算上的「生氣離開 N 組」都跟一般客人一樣**：沒有無限耐心、沒有免費、沒有特權。
  - 怡君在秀琴阿姨走過去認她以前：評論上的名字是「一位客人」（以前會直接寫「怡君」，也是破壞故事順序），也不用她自己的話。
- **Madame Lin**：還是會過來吃飯（「她什麼都看得到」那條故事就在這些晚上），但隨機抽 VIP 時：《隔壁》之前不會是她、不會是「VIP 預約」
  預約的那位、不會在「饕客尖峰」那一群裡、她自己最後一晚不會過來；她第一個到時，不跳「VIP 貴賓到了！消費高，要求也高。」。故事自己
  安排的來店照舊。
- **王家三口**：一般客人的「王家三口」改成「一家三口」；一般客人的名字（包括名字用完時的備援）都沒有王姓。熟客王先生、王太太不變；
  舊存檔裡「王家三口」寫過的評論照原樣保留。
