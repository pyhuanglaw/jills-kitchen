  一般客人），有 16 個名字出現不只一次。v2.5.3 原本的遊戲直接跑這個測試會在開頭就停（測試要讀新加的備援名單），所以用這個版本代表。
  第一次寫好時測試就抓到一個沒想到的情況：「美食家」這一類自己的名字只有 Chloe、Emma 兩個，後期一晚的美食家多，連 8 個備援名字都
  用完，又開始重複 —— 所以改成大人可以借用上班族那一批沒用過的名字（`no_borrowing` 就是沒有這一步的版本）。
