# 商店 › 員工的總表：每個人做什麼那一欄只剩一個點（Audit WS2-15，比當時更嚴重）

**看到的**（使用者第 92 天存檔，商店 › 員工，`before_375.png`、`before_390.png`）：「外場」總表每一列是「名字・等級・負責什麼・數字」。
「負責什麼」那一欄（例如「帶位＋點餐＋上菜＋結帳・Lounge」）在 375 寬只有 0 px、390 寬 3 px，畫面上只看到一個小點；廚房、清潔員的表也一樣。
Audit 當時記的是「被省略號切掉」，現在連字都看不到。

**原因**：右邊那欄數字（「一次端 4 盤、一趟送 3 桌・反應 0.5 秒」）不換行、佔掉整列，負責什麼那欄被擠到 0。

**修法**：數字移到名字那一列的下一行（`after_375.png`）。負責什麼那欄有完整的寬度。

**測試**：`qa_the_staff_tables_show_what_each_one_does`（375、390、430 寬，從商店點進員工分頁）：每一個「負責什麼」完整顯示、跟名字和
等級在同一行，數字在下一行，表格不超出畫面。`mutants.txt`：修之前、數字沒有自己一行（表格排亂、整頁可以左右滑，
`mutant_numbers_without_own_line_375.png`）、數字不見，三個都失敗。第一版測試沒有抓到第二個做壞的版本，所以把排版的檢查加進去了。
