# 坐下來才生氣走掉的客人，評論寫「客滿，沒等到位子。」（2026-10-13）

**使用者存檔裡找到的**（`tests/saves/*.json` 的 `reviews`，一星、標籤 left＋wait）：
- 「客滿，沒等到位子。」90 則（其中 37 則後面接貓的句子，例如「客滿，沒等到位子。樾樾在店裡跑來跑去…」）——寫這些的都是已經
  坐下、等到「生氣地離開了…」的客人，明明有位子。
- 「餓著肚子離開了，Jill 下次見。」100 則——其中有一部分是已經吃完、只是等結帳太久才走的客人。
- 在門口排隊等不到位子走掉的客人（二星）照樣可以寫「客滿，沒等到位子。」，那是對的。

**原因**：坐著生氣走掉的那條路（`angryLeave` 的桌邊那段）和門口那條共用同一組「離開」句子，評論不知道客人坐過、吃過。

**修法**：桌邊那段告訴評論「坐過」（seated）、「吃過菜」（ate）；評論只挑對這位客人是真的句子。沒有新寫任何句子。

**測試**：`qa_a_table_that_gave_up_does_not_review_the_door`（tests/qa_tests.py），走遊戲自己的 `angryLeave`：60 組坐著沒吃、
60 組吃完等結帳、120 組在門口。修之前的版本和 4 個故意做壞的版本都失敗（`mutants.txt`）。
