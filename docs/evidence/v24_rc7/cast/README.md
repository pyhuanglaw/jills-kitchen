# 有故事的客人：自己的髮型與臉（v2.4 rc7，2026-10-02 17:50）

玩家 15:38：「有劇情的npc在遊戲裡的臉和髮型可不可以特別一點 不要都跟別人一樣」。

## 改了什麼

- 髮型 10–23 只給有故事的客人，照他們的肖像畫畫（`drawStoryHair`）。一般客人的髮型還是從 0、1、2、3、6、7、8 裡抽，所以陌生人永遠不會有這些髮型。
- 臉和身上的細節也一樣（`drawStoryFace`、`drawStoryWear`），一般客人都不會有：
  - 各自的眼鏡：Ken 細框、王先生粗框、李先生和檢查員金屬框、Mr. Hart 圓形墨鏡。原本那種圓框眼鏡現在只給陌生人。
  - 鬍子：杜的山羊鬍、Mr. Hart 的白鬍子、小林的鬍渣。
  - 眉形、睫毛、唇色。
  - 首飾：王太太和 Madame Lin 的珍珠、耳環。
  - 杜的領巾（劇情文字早就寫「打領巾的客人」）、Mia 的吊帶褲、小琪的相機。
- 換掉跟陌生人一樣的配件：Sophie 的貝雷帽、Mia 和 Madame Lin 的圍巾、小林的領帶、Leo 的背包、陳伯伯的眼鏡（肖像沒有戴）。衣服改成肖像上的樣子。
- 陳伯伯維持年長男性的髮型 5（一般客人本來就不會有），Dylan 維持 9，戴帽子的客人維持他的帽子（喬裝）。

## 測試

`v24_rc7_story_guests_have_their_own_faces` 檢查以下幾件事：

- 1,500 次陌生人抽樣（8 種類型 × 3 個房間）：髮型只出現 0–4、6–8，沒有任何故事細節，也沒有帽子。
- 每個有故事的客人（7 位熟客、12 位有名字的客人、Dylan）都有陌生人不會拿到的髮型。
- 沒有兩個人的髮型和髮色都一樣。
- 沒有人戴陌生人的圓框眼鏡或貝雷帽。
- 14 種髮型都有人用。
- 每種髮型在 4 種姿勢下都畫得出跟短髮（0）不一樣的東西。差別至少 700 像素，門檻 120。

`named_guests_keep_one_face_and_the_staff_have_theirs` 原本寫死「10 位 + 怡君」。rc7 加了林予安以後，這個測試就失敗了。這裡改成「原本的 10 位 + 每個 story 角色」。

## golden_frames 的重錄證明

第一次跑：第 2 天第 90 個取樣（t=90.0）的 `scene` 不同（`golden_frames_before_rerecord.log`）。這兩天裡唯一會出現的故事客人是陳伯伯（第 2 天起會來）。

`python3 tests/run_tests.py --record -k golden_frames`
