# Version 17：Dylan 出場頻率校正 + 視覺打磨 + 一個真正的畫面消失 bug

基準：`git tag baseline-v16`（V16 完成時的 commit）。本版不加新玩法、不重做做菜流程、不重構生活系統。

## 0. 先修的 blocker：第 5 天餐廳整個消失

**現象**：真實遊玩到第 5 天 17:00，HUD 和點爐台的提示還在，餐廳（地板、桌子、Jill、貓、所有 Canvas 世界）不見了，只剩深棕色底。

**原因**（不是第 5 天特有）：員工外觀 `crewLook(m)` 用 `hash(m.id)` 挑髮色，`hash()` 回傳的是無號 32 位元整數，但程式用**有號位移** `h>>3`、`h>>6`。大約一半的員工 id 位移後是負數，`HAIR[-2]` 是 `undefined`，畫到那位員工時 `drawPerson` 裡的 `shade(undefined)` 丟例外。例外發生在 `drawScene` 裡，也就是在 `requestAnimationFrame` 的回呼裡，所以整條 rAF 鏈就此斷掉：時鐘停在 17:00、世界不再重畫。DOM 的 HUD、toast、點爐台的 pointer 事件都不經過那個迴圈，所以「還能動」。之後瀏覽器只要 resize 一次（手機網址列伸縮就會），`layoutAll` 重設畫布尺寸、畫布被清空，露出 `#sceneWrap` 的深棕色底 — 就是截圖那個樣子。

玩家是第 4 天晚上雇了人，第 5 天開店的第一幀第一次畫到那位員工就中了。任何一天雇到 hash 落在符號位的員工都會發生；廚師在爐台上的小頭像也走同一條路。這個 bug 從 v13 baseline 就存在，V16/V17 沒有引入它，但 V16 之前沒有人在測試裡真的雇過人。

**為什麼測試沒抓到**：測試裡的員工 id 是 `w1`、`c1` 這種手寫值，`w1` 剛好 hash 成正數；`long_play_is_stable` 連玩十天但從不雇人；其他用到員工的測試只跑模擬（`__bot`）不畫畫面。

**修法**：`h>>3`、`h>>6` 改成 `>>>`（一行）。沒有 try/catch、沒有定時重畫、沒有重建畫布。

**新測試** `world_stays_visible_across_days`：像真人一樣連玩 10 天（每天買桌子、升設備、研發、裝潢、雇員工、擴建；第 4 天另外塞進 `c1`、`m1` 這兩個 hash 為負的 id），每一天每一秒檢查：畫布中段真的有餐廳（非底色比例 <30%、顏色數 >300）、時鐘在走、沒有 page error、`sctx` 的 save/restore 深度歸零、globalAlpha=1、composite=source-over、所有人和貓的座標是有限值；換日、結算、商店、隔天開店前的房間也檢查。在修之前跑它，會以同一個例外失敗。另外 `v16_save_continues_in_v17` 用一份真的 V16 存檔（含遊戲自己產生的員工 id）開店、畫 8 秒、換日、備份、讀回、再玩。

## 2. 視覺

先截了 16 個狀態的圖（`scratchpad/audit/before_*.png`）在遊戲實際尺寸看。最明顯的「prototype 感」來源：人物是貼紙（平塗、沒有眉毛鼻子、所有人同一個身體）、地板是一大片平的米色、家具沒有接觸陰影、一天從頭到尾光線幾乎一樣、食物在桌上看不出蒸氣。

做了什麼（全部是程序繪圖，沒有外部素材）：

- **人物（`drawPerson` 重寫，座標與尺寸不變）**：眼白＋虹膜＋高光、眉毛（依情緒角度）、一筆小鼻子、嘴唇色、耳朵內側、下巴在脖子上的陰影；髮型多了 3 種（側分短髮、蓬鬆鮑伯、側掃長髮），頭髮多一層底部暗色與頂部高光；肩膀受光、袖口、腰線陰影、V 領/圓領；雙層柔和地面陰影。Jill 多了 `expr`：`smile`（招牌的彎彎眼）、`focus`（做菜、趕路時：眼睛微瞇、嘴平）、`soft`（沙發上）、`tired`（打烊開始與剛坐下的前 25 秒）、`amused`（Dylan 演戲時挑一邊眉毛）。Dylan 換成側分短髮、其餘照舊，揭露前後不變。員工髮型也由 hash 分配（修好位移後）。
- **五隻貓**：雙層柔和陰影、坐著/站著不動時的呼吸起伏。臉、耳朵、條紋、蓬鬆感本來就有，沒有動個性與行為。
- **光線**：`tintFor(d)` 三段式：開店清亮 → 傍晚暖橘 → 打烊偏藍灰；打烊後多一層以沙發為中心的徑向暗角（Jill 在沙發時光聚在沙發，否則在房間中央），營業中不套。地板多了暗角與牆腳的落影、極淡的織紋。
- **接觸陰影** `softShadow()`：桌子、椅子、植物、跳台、長椅、沙發、閨蜜機都改成寬淡＋窄深兩層。
- **桌椅**：桌面加了受光邊與暗邊；木椅有兩片背板和上橫檔、座面高光。
- **食物**：沙拉葉更亮更大並多了油醋光點、烤蔬菜多了紅椒與南瓜塊和焦邊、生火腿更飽滿、燉飯更奶油並撒起司片、炒飯的蛋塊看得出是蛋。桌上剛上的熱食（主餐、湯、咖啡、紅茶）冒兩縷蒸氣。
- **做菜回饋**：翻面時鍋裡的東西跳起來翻過去（0.42 秒）、煎的時候油星從鍋裡濺出。原有的火焰、熱氣、蒸氣、倒飲料的水柱、奶泡都保留；飲料的量表機制沒動。
- **等候長椅**：木椅座面鋪了一條和沙發同色的長坐墊（縫線、高光），坐著等的人有呼吸起伏。
- **沙發**：背墊滾邊、右角一顆綠色抱枕（貓會蓋住它，那是正常的）。
- **動畫**：桌邊客人、長椅客人、不動的貓都有慢速呼吸；其餘沿用（眨眼、尾巴、蒸氣、翻書、馬尾）。沒有同步、沒有到處都在動。
- **UI**：沒有動（餐廳本身該是主角）。

前後對照圖：`scratchpad/audit/cmp_*.png`、`people_before/after.png`、`faces_after.png`。

## 3. 效能

真實時間、無頭 Chromium、第 12 天忙碌時段（6 桌、員工、貓）：

| | 之前 | 之後 |
|---|---|---|
| `drawScene` 平均（忙碌第 12 天） | 2.64 ms（p95 3.4） | 3.00 ms（p95 4.2） |
| `drawScene` 平均（第 1 天） | 2.46 ms | 2.62 ms |
| Canvas 呼叫／幀（忙碌） | ~6050 | ~6700 |
| 各函式（忙碌）| 貓 1.36、人 0.25、桌 0.17 | 貓 1.32、人 0.34、桌 0.26 |

新增的東西幾乎都是每幀幾個 fill：人物多約 12 個形狀（兩隻眼睛的每一層合成一條 path）、貓多 1 個橢圓、每張桌子多 3 個描邊、營業中全畫面沒有多任何漸層（打烊後才多 1 個徑向漸層）。背景（地板織紋、暗角）在 `makeBg` 的快取裡，不佔每幀。貓一直是最貴的（蓬鬆毛的圓、條紋的 clip），這版把毛的圓合成一條 path，但量測上差異在雜訊內。

31 項（V16 的 29 項 + `world_stays_visible_across_days` + `v16_save_continues_in_v17`），多檔版與單檔版都通過。黃金基準重錄前確認：第 1、2 天的貓行為與決策權重雜湊和 V16 完全相同（只有畫面像素與含圖片的 DOM 不同），第 3 天起因為 Dylan 的骰子改了而分歧。

## 6. Canvas 的天花板

用程序繪圖能做到的，這版大致做到了：人物有表情、有光影，但頭永遠是一個圓、身體永遠是圓角矩形。再往上要的是**手繪素材**：

1. **Jill 與 Dylan 的角色圖**（各 4–6 個姿勢 × 2 個方向）：影響最大，他們是畫面中心。
2. **五隻貓的姿勢圖**（坐、趴、睡、走、理毛，各 2 方向）：現在的貓靠形狀拼，換成手繪後個性會更明顯。
3. **餐點成品圖**（24 道 + 招牌菜組合）：桌上 18px 的小圖用手繪會清楚很多。
4. **手繪背景板**（牆、地板、窗）：一張圖就能取代現在 7000 個點的程序地板，而且更好看、更省。
5. 家具與道具（沙發、跳台、長椅、閨蜜機）：次要。

程式這邊已經替換得動：人物走 `drawPerson`、貓走 `drawCat`、食物走 `dishCanvas` 快取、背景走 `makeBg` 快取，各自只有一個入口。
