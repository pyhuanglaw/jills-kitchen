# 生活系統：沙發、閨蜜機、Jill 的打烊後、Dylan

> 開發文件。遊戲裡不會出現這份文件的任何說明；玩家只會看到畫面。

## 0. 設計原則

- **沒有劇本函式。** 沒有 `familyNightScene()`、`romanceScene()`。每個角色（Jill、Dylan、五隻貓、閨蜜機）每一步都只看自己的狀態、個性、沙發上還有什麼位子、其他人在哪、冷卻時間和機率，自己決定下一步。
- **一份共用的「佔位」規則**：沙發座墊是一條 x 軸區間（100–196），誰坐了哪一段就登記哪一段。Jill 的身體、她伸直的腿、Dylan、每隻貓都用同一套區間檢查，所以不會穿模，也不需要為每種組合寫規則。
- **營業中玩家永遠優先。** 生活系統只在 `evening()` 為真時運作（打烊流程、結算、商店畫面）。營業中 Jill 完全由原本的服務邏輯控制。
- **不新增任何數值管理。** 沒有疲勞、娛樂、好感度；沒有任務、沒有彈窗。

程式在 `js/game.js` 的 `/* ===== life: the sofa, the rolling TV, Jill's evenings, Dylan ===== */` 區塊，加上少量掛鉤（貓咪決策、客人流程、繪圖、存檔預設）。

## 1. 沙發

`SOFA = {x0:88, x1:208, back:86, seat:112, front:142, …}`，在窗戶下方、招牌左邊。為了放下它：貓抓柱從 (152,114) 移到 (226,114)，裝潢植物聚到抓柱右側（240–278）。

**可以坐的地方**（`sofaSlots(c)` 每次即時計算）：

| 種類 | 位置 | 規則 |
|---|---|---|
| seat | x = 112 / 136 / 160 / 184 | 區間 [x−12, x+12] 必須完全空著 |
| lap | Jill 腿上（腿伸直時在腿的中點；收腿時在大腿上） | 只有 Jill 在的時候，一次一隻 |
| arm | 左右扶手 | 各一隻；Dylan 坐在旁邊時那側不開放 |
| back | 椅背 x = 114 / 140 / 166 / 192 | 不能正好在 Jill 或 Dylan 頭後方 22px 內；貓之間距離 ≥ 25 |

Jill 有三個位置：`L`（x 122，腿往右伸，電視放右端）、`R`（x 174，腿往左伸，電視放左端）、`M`（x 148，正坐）。她 70% 先試 L，位子被貓佔走就換；全部都有貓就回到原本的第一桌坐（舊行為）。她一決定要去哪裡就會**預約**那段區間，貓不會搶。

**腿**：`legs` 0→1 漸變。坐好後如果腿要伸的那段沒有貓就伸直（85%）；之後每隔一陣子還會試一次。Dylan 坐到她腳邊時，`legTarget` 降到 0.75——這就是「挪一下腿」。

## 2. Jill 的晚上

打烊開始（`startClosing`）→ `lifePlan()`：85% 去沙發，15% 照舊坐在第一桌。

到沙發後的活動由 `jillDecide()` 用權重挑：看電子書（4）、什麼都不做（2.4）、看閨蜜機（2.4，電視推不過來就 0）。剛做過的事權重減半。每個活動 10–90 秒，然後再挑。

小動作：翻頁（5–13 秒一次，手抬一下）、有貓剛跳到她旁邊時看一眼（`gazeT`）、偶爾摸一下貓（`pet`，貓會冒愛心）、每 25–50 秒重新靠好（`bobT`）。安靜本身就是一個狀態（`idle`）。

**閨蜜機**（`LIFE.tv`）平常停在右邊牆角 (352,118)。
- 想看的時候：40% 的晚上她在去沙發的路上就順手推過來；否則坐下後才想看，就先把腿收起來、站起來、走過去推。
- 推的路線：先往下拉到走道 (y 146)，再沿走道推到沙發她那一側的端點。前方 26px 或車身 19px 內有貓就停下來等，等超過 5 秒就放棄（電視留在原地，`tv.tried++`，她回去坐）。
- **腿上有貓的時候她不會起來**（`lap` 有貓 → 不會進入 `fetch`），除非 Dylan 在場、有可能替她推。
- 沒人看 25 秒後電視自己關掉。附近正在休息的貓有 30% 會把臉轉向電視幾秒，其他貓不理它。

## 3. 五隻貓與沙發

沒有重寫任何個性，只多了一個地方可去：`catDecide` 多了 `sofa` 選項（`sofaWeight`），和 Jill 在沙發時把 `jill` 選項導向 `goSofaJill`。

| 貓 | 沙發權重與偏好 |
|---|---|
| 包包 | 2.4；只想要座墊（seat 3，角落 ×1.4，扶手/椅背 ×0.1）；沒座墊就寧願去別處。到了就 80% 直接睡 30–90 秒 |
| 寶寶 | 2.2；椅背 3、扶手 2.2、座墊 0.8；越擠越不想去（`crowd`）。椅背右側的毯子是她最常選的位子 |
| 樾樾 | 0.7，但 Jill 在的時候走 `jill` 選項（傍晚 ×2.6）：依距離挑最靠近 Jill 的位子；Dylan 在旁邊也會吸引他 |
| 小齁 | 0.6；同樣依距離挑靠近 Jill 的位子，還會偏向樾樾旁邊 |
| 柔柔 | 0.9（寶寶在沙發上時 +1）；偏向小齁、樾樾、寶寶旁邊；埋伏點多了「沙發右扶手後面」和「閨蜜機旁邊」 |

**樾樾 × 小齁的競爭**（`goSofaJill`）：先到的拿最近的位子。後到的發現對手更近時：20% 坐到地上 Jill 腳前等、12% 放棄去別處、剩下的接受第二近的位子。沒有任何規則寫「誰在左邊誰在右邊」——30 個晚上裡有 14 個晚上自然形成一左一右。

**上下沙發**：走到沙發前緣 → 跳上座墊 → 需要的話再跳到扶手或椅背（`chain`）。離開一律跳到地上再決定下一步。停留機率：包包 .85、寶寶 .6、樾樾 .78（Jill 在）/.4、小齁 .72/.4、柔柔 .45，傍晚 +.08。樾樾、小齁留下時 25% 會換到更靠近 Jill 的位子。

貓走路不會穿過沙發（`catWalk` 遇到會繞到前緣下方），隨機落點也不會落在沙發裡。

## 4. Dylan

`DYLAN` 常數 + `REG_BY.dylan`，不在 `REGS` 名單裡，所以不走一般熟客的排程和台詞。

**營業中**（第 3 天起，每天 30%，連續兩天只有 10%；揭露後 42%）：
- `freeTableFor`：挑離出餐口最遠的空桌——看得到 Jill、不擋路。玩家指定桌子時照玩家的。
- 耐心消耗 ×0.5。
- 每 8–20 秒看 Jill 一眼（`g.gaze`，眼珠偏移 1–3 秒）；Jill 面向他、距離 80px 內就立刻移開視線。
- 45% 點招牌菜（有的話）。點餐時不說話；Jill 空下來時偶爾一句（一次來店最多一句）：「今天人很多。」「貓咪們今天很乖。」「外面開始下雨了。」揭露後換成「今天很累了吧。」「不急，我等妳。」「貓都在。」
- 貓從第一天就把他當家人：`familiar()` 對他永遠為真（樾樾不會對他警戒；一般熟客要來 6 次），樾樾/柔柔/小齁有機會主動去他桌邊（`visitDylan`），樾樾也會像對老客人一樣睡在他桌旁。

**隱藏進度** `S.dylan`（存檔裡，UI 永遠不顯示）：`{stage, stay, reveal, last, clues:{late,pet,tv,tidy,look}}`。每天開店時 `dylanStageCheck()`：

| 階段 | 條件 | 打烊後會做的事 |
|---|---|---|
| 0 | — | 一定離開 |
| 1 | 來店 ≥ 3 次且第 6 天以後 | 吃完時如果已經打烊（或當天 ≥ 80%），40% 留下：坐在別桌用手機、站在門邊、蹲下來陪貓、幫 Jill 推閨蜜機、把自己的盤子端到出餐口（普通客人不會知道盤子放哪）、然後離開 |
| 2 | 第 12 天以後、來店 ≥ 6、留下 ≥ 2 晚、線索 ≥ 3 種、Jill 在沙發上待過 ≥ 3 晚、貓和他互動過 | 同上；每個晚上擲一次骰子（40%），擲中而且 Jill 已經坐好、腳邊有位子時，他過去坐下 |
| 3 | 揭露後 | 65% 留下：坐在 Jill 身邊（用手機、一起看電視、什麼都不做）、偶爾一句話、Jill 有時回一句「嗯。」；位子被貓佔滿就坐別桌；貓有時擠在兩人中間 |

**揭露**（`doReveal`）：他坐下 2.5 秒後拍一張生活照，標題「Dylan — Jill 的先生」（用既有的回憶照片機制，只有快門和閃光）；手冊熟客頁他的標籤從「熟客」變成「Jill 的先生」，描述一行。沒有橫幅、沒有愛心、沒有對話。遊戲照常進行。

Dylan 走到沙發時也會預約他那段區間；揭露後貓挑位子時會把「他常坐的那段」權重 ×0.35——但不是禁止，所以還是常常被貓占走。

## 5. 存檔

`newState()` 多了 `dylan` 與 `life:{sofa, tv}`。舊存檔讀進來由 `fillDefaults` 補上，測試 `old_saves_load` 有檢查。`LIFE`（當晚的即時狀態）不存檔：讀檔進入商店畫面時 Jill 會直接坐在沙發上，Dylan 視為已經回家。

## 6. 測試

| 測試 | 檢查什麼 |
|---|---|
| `sofa_geometry` | 三個 Jill 位置 × 三種腿 × 有沒有 Dylan，貓把沙發塞滿後沒有任何區間重疊、沒有人掉出座墊；Jill 伸直腿後至少還能坐 4 隻貓 |
| `jill_evening_life` | 12 個固定種子的晚上：≥ 8 晚用沙發、伸腿的晚上 ≥ 一半、看書和發呆都出現過、電視至少一晚、貓的數量有變化、晚上結束時沒有人卡在站著 |
| `cats_use_sofa_by_personality` | 16 個晚上的統計：包包 ≥ 55% 在座墊而且大多在睡；寶寶 ≥ 55% 在椅背或扶手；樾樾、小齁 ≥ 60% 的時間在 Jill 50px 內，而且最近的位子兩隻都拿過；出現過 Jill 一個人坐著的時刻 |
| `dylan_stays_a_quiet_regular_early_on` | 前期：耐心比其他熟客高、有看 Jill、階段 0 時從不留下、手冊沒有任何關係字樣或戀愛 UI |
| `dylan_hidden_reveal` | 揭露只發生在 Jill 已在沙發、他坐到她身邊之後；之前手冊沒有「Jill 的先生」、之後有；揭露後他至少有一晚坐在她旁邊；遊戲繼續 |
| 所有狀態檢查（`INV`） | 多了沙發不變條件：一個位子一隻貓、腿上最多一隻、座墊區間不重疊、Jill 坐著時位置正確、電視不會撞到貓 |
