## 怎麼做的

- **每道菜每一站有自己的一串「拍」**：`CH[菜][站]`（`js/game.js`）。每一拍寫：到哪裡結束、手在做什麼動作（倒、下料、切、
  拌、翻炒……）、手上拿什麼、這一拍帶來的樣子（例如「蛋液 0 → 1」）、一句話說這一拍（只給文件和截圖用，遊戲裡不顯示）。
- **一站分兩段**：「手」——做這一步的人在那裡，放進去的東西都是手放的；「火」——自己煮（或機器自己做、茶自己泡），沒別的事
  的人會留下來顧，畫面一樣會變。兩段的時間都是原本 `wfTimes` 的數字，**這一輪沒有改任何時間、按鍵、流程或容量**。
- **`chState(n, 站)`** 回答使用者的問題「這道菜現在這一站做到哪、鍋裡應該看見什麼」；畫的程式 `CHD[菜]` 只照這個狀態畫。
- **裝盤也是一串拍**：在食物旁邊，一次一次盛到盤子上，最後一刻才換成那道菜原本的完成圖（`dishCanvas`）。
- **使用者的 HARD RULES，每次測試都檢查**（`cooking_each_dish_with_its_own_beats_starts_raw_and_changes_by_hand`）：
  - 加東西進去的拍一定在「手」那段，不會在「火」那段自己冒出來；「手」的每一拍都有動作；
  - 每一站開始時是生的／空的，拍走完才是這一站做好的樣子；
  - 真的畫出來比對：開始、手做完（沒有火的站：手做到一半）、做好，三個時間點畫出來都不一樣——沒有「一開始就是完成品」。
- 加一道菜：寫它的 `CH` 拍和 `CHD` 畫法，跑上面那個測試，拍 `tools/qa/dish_frames.py` 的逐拍截圖、`tools/qa/dish_sheet.py` 的總表。

## 每道菜的拍

**黃金蛋炒飯**（熱區 → 裝盤）　熱區（手）熱鍋下油 → 倒入蛋液 → 蛋炒到半熟 → 下白飯 → 加蔥花 → 翻炒；（火）炒到粒粒金黃。
裝盤：一鏟一鏟盛進盤子 → 整成一份 → 撒上蔥花。

**拿鐵咖啡**（飲料 → 送飲料）　（手）杯子放在咖啡機下、按下萃取 → 深色的濃縮咖啡從出水口流進杯裡 → 熱牛奶從牛奶壺倒下去，
咖啡由深變成拿鐵棕、最後一下留下愛心；（火）奶泡浮上來、拉花變清楚。送飲料：做好的杯子端到出菜口。

**錫蘭檸檬紅茶**（飲料 → 送飲料）　（手）從茶壺倒入熱紅茶（淡淡的） → 檸檬片從手上落到茶面 → 湯匙輕輕攪拌；（火）茶色慢慢
泡成琥珀色。

**檸檬氣泡水**（飲料 → 送飲料）　（手）冰鏟把冰塊一塊一塊放進空杯 → 綠色的瓶子倒氣泡水，水位上來、冒出很多氣泡，冰塊浮起來
→ 檸檬片放進去；（火）氣泡慢慢往上冒。水一直是透明的（看得到後面的流理台），不像白色飲料。

**田園沙拉**（備料 → 裝盤）　（手）砧板上一顆生菜、一顆番茄、一條小黃瓜 → 刀切生菜（生菜變小、旁邊一堆葉子） → 切番茄（先
對半、再變成一瓣一瓣） → 切小黃瓜（一片一片從尾端切下來） → 刀面把三堆菜依序推進砧板右邊的碗裡（生菜、番茄、小黃瓜一樣一樣
進去） → 小瓶子淋上油醋醬 → 沙拉夾拌勻。裝盤：沙拉夾一次一次從碗裡夾進客人的碗（碗裡的變少、客人碗裡的變多） → 撒上麵包丁、
一條醬汁線。

**番茄義大利麵**（熱區 → 裝盤）　（手）白色的碗把煮好的麵條倒進平底鍋（淡黃色的麵一條一條進去） → 小鍋子倒入番茄醬汁（麵上
一灘紅醬） → 翻拌；（火）拋鍋翻拌，紅醬被拌開、麵條從淡黃變成裹滿番茄醬的橘紅色，冒蒸氣。裝盤：麵夾一次夾起一捲放到盤子上
→ 整成一捲、醬在上面 → 撒起司、放羅勒。

**南瓜濃湯**（熱區 → 裝盤）　（手）碗把南瓜塊倒進空鍋 → 壺倒入高湯（淡金色） → 倒一點鮮奶油（白色紋路） → 攪拌；（火）一邊
攪拌，南瓜塊越煮越小、湯從淡金色變成滑順的橘色，鮮奶油混進去、顏色柔和一點，冒蒸氣、小泡泡。裝盤：湯杓一勺一勺舀進湯碗
（鍋裡變少、碗裡湯面升上來） → 淋一圈鮮奶油（畫出螺旋） → 撒南瓜籽和麵包丁。

**經典牛肉漢堡**（備料 → 熱區 → 裝盤）　備料（手）麵包兩半放左邊、一團生牛絞肉用手壓成一片生肉排 → 撒鹽和黑胡椒 → 刀把番茄
切成片 → 生菜放旁邊。端去熱區：手上一盤，生肉排、麵包、番茄、生菜。熱區（手）生肉排從手上放到煎台；（火）貼著煎台的那一面
變褐色（看得到邊緣變色、油花噴起）→ 翻面（有人顧著就是煎鏟翻；沒人就自己翻，規格寫「中段自動 flip」），煎好的那面朝上、有
烤痕 → 第二面繼續上色。裝盤：下層麵包 → 生菜、番茄 → 煎好的肉排從煎台夾過來 → 起司 → 擠醬 → 蓋上上層麵包 → 旁邊放薯條
（原本的完成圖就有薯條）。

**焦糖布丁**（備料 → 裝盤）　（手）空的玻璃模子 → 小鍋倒焦糖，底部一層深色 → 壺倒布丁液，慢慢填滿，表面還在晃 → 放進冰箱：
模子上一層冷氣、霜往上飄，布丁變得穩定、顏色深一點（規格：「內部等待／定型可以自動發生」——這一段沒有玩家操作）。裝盤：模子
從砧板拿起、在盤子上方翻過來、放下 → 輕輕提起模子，布丁站在盤子上，原本在底部的焦糖現在在頂上 → 焦糖從頂上流下來、積在
周圍。

**松露薯條**（烤箱 → 裝盤）　（手）碗把淡色的生薯條倒在烤盤上 → 烤盤推進烤箱（往烤箱門移動、變小）；（火）從烤箱門的窗看得到，
薯條從淡黃烤到金黃，尖端稍深。裝盤：烤盤從烤箱拉出來放在烤盤架上 → 薯條一夾一夾盛到墊紙上 → 撒鹽和香草 → 刨上松露、放
一小碟醬。

**莓果蘇打**（飲料 → 送飲料）　（手）冰鏟放冰塊 → 小瓶子倒莓果糖漿，柳橙片和莓果一起掉進去，杯底紅色 → 倒氣泡水，杯底紅、
往上變粉紅、最上面接近透明（漸層） → 湯匙攪拌成均勻的莓果色 → 放上莓果、薄荷，插上吸管；（火）氣泡慢慢往上冒。

**香料烤蔬菜**（備料 → 烤箱 → 裝盤）　備料（手）一顆紅椒、一條紅蘿蔔 → 刀切成大塊（整顆的越切越小、旁邊一堆塊） → 一塊一塊
排到砧板尾端的小烤盤上 → 淋橄欖油（亮亮的） → 撒香料。端去烤箱：手上是排好的烤盤。烤箱（手）推進烤箱；（火）從新鮮的
紅、橘色烤成深一點的焦糖色，邊緣變深。裝盤：拉出烤盤 → 一塊一塊盛到盤子上 → 放一枝迷迭香。

**提拉米蘇**（備料 → 裝盤）　（手）玻璃盤裡手指餅乾一根一根排在底部 → 刷子刷上咖啡液，餅乾變深 → 抹刀從一頭把馬斯卡彭
鋪過去 → 第二層手指餅乾 → 再刷咖啡液 → 再鋪一層 → 表面抹平。裝盤：切下一份、移到盤子上（盤裡少一塊） → 最後才撒可可粉
（規格：「最後才撒 cocoa powder」） → 放一片薄荷。

**香草烤雞**（備料 → 烤箱 → 裝盤）　備料（手）生雞腿（粉白）和馬鈴薯 → 抹油（發亮） → 香草抹在雞皮上，一直看得到 → 撒鹽
→ 雞腿和馬鈴薯移到砧板尾端的烤盤上。端去烤箱；（手）推進烤箱；（火）粉白的雞皮烤成金黃，最後一段烤皮更明顯，馬鈴薯也上色。
裝盤：拉出烤盤 → 雞腿移到盤子上 → 烤馬鈴薯放旁邊 → 迷迭香和一塊檸檬。

**炙烤肋眼牛排**（備料 → 熱區 → 裝盤）　備料（手）明顯是生的肋眼（紅色、白色油花） → 撒鹽 → 撒黑胡椒 → 輕壓讓調味貼住（還是
生的）。端去熱區（手上一盤生牛排）。熱區（手）生牛排下鍋 → 一塊奶油和一枝迷迭香放在鍋邊；（火）第一面貼著鍋慢慢褐化、冒油花
→ 翻面，第一面是漂亮的焦色和烤痕 → 第二面上色，奶油在後段慢慢融化成金黃的泡泡，有人顧著就用湯匙一勺一勺淋在牛排上。裝盤：
牛排移到盤子上 → 切幾刀，然後切片排開，看得到熟度（照客人點的熟度） → 淋上奶油醬 → 迷迭香、一小塊奶油、鹽花。

**巴斯克乳酪蛋糕**（備料 → 烤箱 → 裝盤）　備料（手）奶油乳酪和糖放進攪拌盆 → 蛋液和鮮奶油慢慢倒進去 → 打蛋器攪拌，塊狀變成
滑順的淺色麵糊 → 倒進鋪好烘焙紙的蛋糕模（模裡麵糊升上來）。端去烤箱；（手）推進烤箱；（火）淺色麵糊膨起、定型 → 表面烤出巴斯克
特有的深褐色焦面。裝盤：從烤箱拿出來 → 刀切一片、放上盤子（模裡少一角） → 旁邊放莓果。

**生火腿沙拉**（備料 → 裝盤）　（手）生菜和芝麻葉切好 → 推進碗裡 → 淋醬汁 → 沙拉夾輕輕拌。裝盤：沙拉先放上盤子 → 生火腿一片
一片鋪上去（規格：生火腿不跟生菜一起被切碎） → 起司片、無花果、幾滴巴薩米克醋。

關的） → 蒜頭切片 → 煮好的麵分成一份。端去熱區。熱區（手）蒜片、生蝦、淡菜從碗裡倒進鍋 → 加麵 → 倒高湯和白酒 → 翻拌；（火）
一直翻拌，蝦變紅、捲起來，淡菜一個一個打開露出橘色的肉，麵條裹上醬汁、變金黃，海鮮分散在麵裡。裝盤：麵用夾子捲起來放進盤子
→ 蝦和淡菜一個一個夾到麵上（鍋裡的一個一個少） → 撒香草、放一塊檸檬。

**香煎鴨胸**（備料 → 熱區 → 裝盤）　備料（手）生鴨胸（深紅的肉、上面一層白色的皮，水滴形） → 刀子一刀一刀在皮上劃出格紋 → 撒鹽

切成幾片排開 → 淋橙醬。

**松露燉飯**（熱區 → 裝盤）　熱區（手）乾的燉飯米從碗裡倒進鍋 → 綠色酒瓶倒一點白酒 → 加一勺高湯（鍋裡一池湯） → 再加一勺 → 放上
一塊奶油；（火）一直攪拌，米粒吸飽高湯、湯汁收乾，變成綿滑的一整鍋，奶油在最後化進去、表面變亮。裝盤：一勺一勺舀到盤子上 →
輕敲盤子讓它自然攤開 → 刨上松露片和起司。

**舒芙蕾**（備料 → 烤箱 → 裝盤）　備料（手）打蛋器在碗裡打蛋白，從一灘透明的蛋白打成白色的尖角 → 拌入蛋黃糊（黃色的紋路） → 倒進

整個烤模放到盤子上 → 撒糖粉、放莓果。

**蒜香蘑菇**（熱區 → 裝盤）　熱區（手）生蘑菇（白白胖胖）從碗裡倒進鍋 → 油和一小塊奶油（奶油慢慢化掉）→ 蒜片 → 翻炒；

**水牛城雞翅**（熱區 → 裝盤）　熱區（手）淡粉色的生雞翅下到有很多熱油的炒鍋 → 翻動，表面開始金黃 → 後段倒入水牛城辣醬，

西洋芹條 → 一小碟藍紋起司醬。

**起司條**（熱區 → 裝盤）　熱區（手）淡色、裹好粉的起司條放進熱油 → 網杓撥開；（火）外皮慢慢變金黃 → 翻一次 → 金黃，

**生蠔**（備料 → 裝盤）　備料（手）砧板上六顆殼還閉著的生蠔 → 生蠔刀從尾端插進去轉、上殼掀起拿到旁邊（旁邊一疊上殼慢慢變多）、

每顆點一點紅蔥醋。

**德國豬腳**（備料 → 烤箱 → 裝盤）　備料（手）淡粉色的生豬腳抹香料 → 皮上撒鹽 → 放上小烤盤。端去烤箱；（手）推進烤箱；
（火）淡色的皮烤成金黃 → 再烤成深金褐色，皮起泡變脆。裝盤：烤盤拉出來 → 豬腳移到盤子上的木板 → 酸菜 → 一匙芥末。

**酒吧披薩、瑪格麗特披薩、蘑菇白醬披薩**（備料 → 披薩烤爐 → 裝盤）　備料（手，在烤盤裡）生麵團壓開 → 醬從中間倒下去（番茄醬；
蘑菇白醬披薩是白醬）→ 湯杓背一圈一圈抹開（瑪格麗特邊留一圈）→ 起司撒滿（酒吧披薩一直鋪到邊）→ 配料一片一片放：臘腸／
撕成一塊一塊的莫札瑞拉／蘑菇片 → 一張生披薩。端去披薩烤爐；（手）披薩鏟送進爐口；（火）餅皮邊膨起、上色（酒吧披薩的邊是
焦脆的蕾絲邊），起司融化起泡、出現烤色，臘腸邊緣捲起變深／莫札瑞拉融開／蘑菇縮小變色。裝盤：披薩鏟拉出來 → 切（酒吧披薩、
白醬披薩切一格一格，瑪格麗特切六片）→ 最後的香草：奧勒岡／新鮮羅勒（最後才放，規格：「basil 不要過早」）／巴西里。

## 簡化的地方、跟規格的順序不完全一樣的地方

- **杯子在手機上很小**（咖啡機前的杯子大約 25 點寬）：拿鐵、紅茶看的是杯面的顏色和倒進去的那一道水流；倒的工具（牛奶壺、
  茶壺、瓶子、碗）畫在食物上方，代表手上拿的東西；人站在流理台後面，手臂做相同的動作。
- **飲料「手」的時間只有原本的 1.4 秒**（一批多 15%）：拿鐵的濃縮和牛奶都在這 1.4 秒裡，很快；之後 3.5 秒是機器的時間，
  畫的是奶泡浮起來、愛心變清楚。時間是原本的，沒有為了動畫拉長。
- **南瓜濃湯的鮮奶油**：規格說「後段加入鮮奶油、顏色稍微變柔和」。放東西進去一定要有手，而熱區的手只在一開始；所以鮮奶油在
  開始時倒進去（白色紋路），煮的時候慢慢混進去，顏色在後段才變柔和；裝盤時再淋一圈當裝飾。
- **紅茶**：規格的順序是「倒茶 → 變琥珀色 → 加檸檬 → 攪拌」。檸檬要手放，所以放檸檬、攪拌在倒茶後馬上做，琥珀色是之後
  自己泡出來的。
- **義大利麵**：熱區從煮好的麵開始（規格：「鍋中先是麵／少量基底」），沒有另外畫煮麵的那一鍋水。完成圖是原本的（金黃的麵、
  中間一團紅醬、羅勒、起司）；鍋裡最後的樣子已經很接近，最後一刻換成原本的完成圖。
- **漢堡的起司**：規格寫熱區「可在後段加入起司並略融化」。熱區後段是火的時間（人可能不在），放東西一定要有手，所以起司在
  裝盤時才放（規格的裝盤順序本來就有起司）。
- **牛排的奶油**：規格寫「後段才加入奶油／香草」。放東西一定要有手，熱區的手只在一開始，所以奶油和迷迭香是一開始就放在鍋邊，
  到後段才融化、冒泡、被淋到牛排上；牛排完成後的「靜置」沒有另外畫。
- **巴斯克蛋糕的形狀**：蛋糕模從側面看（圓模、烘焙紙露出邊），烤的時候是從上面那一圈看到表面膨起、變焦。
- **烤箱裡的東西很小**：烤箱門的窗在流理台正面，烤的時候食物畫在窗後（原本的大小），看得到顏色變化，看不到細節。
- **烤蔬菜只有紅椒、紅蘿蔔兩種**：原本的完成圖是紅色和橘色的蔬菜塊，為了從砧板到盤子顏色都對得上，沒有另外加綠色的。
- **人從流理台前面走到後面是直線穿過流理台**（新廚房從一開始就是這樣，不是這一批造成的）：例如備好的肉從砧板前面端去爐子
  後面，中間有一下子被流理台擋住。改成繞過流理台的一端會多走一段路（等使用者決定，見下面）。
- **鍋子是從斜上方看的**（扁的橢圓）：鴨胸、蝦、淡菜如果跟著鍋子一起壓扁，就看不出形狀，所以它們是「立起來」畫的；鴨胸大約
  半個鍋子大。
- **舒芙蕾**：規格允許用高度表現膨起來（舒芙蕾本來就會膨），所以烤箱裡是真的長高。烤模跟著盤子端出去，烤箱旁不會留下用過的
  烤模（跟布丁的模子一樣；煎鍋、烤盤還是留在原處）。
- **海鮮義大利麵的高湯和白酒**：規格「加高湯和白酒」用同一個倒的動作（一個壺）。燉飯的白酒用綠色酒瓶倒（規格的順序：米 →
  白酒 → 高湯分次加入）。
- **第五批的炸物用湯鍋的形狀畫油鍋**（金黃的熱油、網籃的把手），沒有另外畫一台炸爐；雞塊、起司條、可樂餅浮在油面上，看得到
  顏色變化。**水牛城雞翅用炒鍋**（規格寫「進鍋」、「後段加入 buffalo sauce」）：倒醬要有手，所以醬在熱區手的後段倒，之後拋鍋
  到醬裹勻是火的時間。
- **起司拼盤在端出去的那塊木板上擺**（規格：「目前 branch 新加的木板方向保留」、「不需要重新變成另一張突然出現的圖」），裝盤是
  在原地整理、放葉子，木板直接端走；從盤子架拿來的盤子沒有另外畫。**三種披薩連烤盤端出去**（菜單上的圖就是放在烤盤上）。
  所以這兩種裝完盤，原地不會留下空木板、空烤盤。
- **披薩烤爐在牆上比較高**：送進去時，披薩從爐子下面的流理台往上移到爐口；拉出來時從爐口下來。
- **兩道菜的完成圖補了一點**，讓裝盤最後一拍跟完成圖一樣：可樂餅的第三顆是切開的、看得到起司（規格：「切開或至少有一個能看到
  起司內餡的 visual」）；生蠔每顆有一點紅蔥醋（規格：「最後 garnish」）。其他完成圖沒動。第五批的盤子照完成圖的位置畫（同樣的
  亂數、同樣的順序），所以最後一拍跟完成圖完全一樣。
- **裝盤的盤子會被人擋住一部分**：裝盤的人站在料理旁邊（使用者 10-08 的要求），第一個盤子在她手下，所以有時候盤子的一角
  被她的頭髮或手臂擋住；盤子裡的東西看得到。
