## 一句話

一道菜（或同一道菜的一批）是一個「工作」（work node）。它照自己的流程（例如 熱區 → 裝盤）一站一站走；每一站是廚房裡本來就有的位置，
有容量限制；Jill 和廚師用同一套規則接手。

## 名詞

| 遊戲裡的說法 | 程式 | 廚房裡的實際位置 |
|---|---|---|
| 備料 PREP | `prep` | 冷盤台的砧板（現有 `prep` slots） |
| 熱區 HOT | `hot` | 爐台的爐口（現有 `stove` slots） |
| 烤箱 OVEN | `oven` | 烤箱（現有 `oven` slots） |
| 飲料 DRINK | `drink` | 咖啡機（現有 `bar` slots） |
| 披薩烤爐 | `pizza` | 披薩烤爐（現有 `pizza` slot，固定 1） |
| 裝盤 PLATING | `plate` | 出菜口廚房側（新的 `pass` slots，用出菜口現有的盤位） |
| 出杯 SERVE | `serve` | 飲料放上出菜口取餐側；不占容量 |

水槽、冰箱、冷藏室不是流程的一站；角色可以在動畫裡走過去。

## 工作（work node）

```
{ id, d: 菜, n: 份數, its: [ticket items], si: 第幾站,
  st: 'wait' | 'fetch' | 'go' | 'work' | 'cook' | 'ready',
  slot: 占用的位置, to: 要去的位置, who: 'jill' | 廚師 id | null, act / pas: 這一站剩下的手作／自己煮的時間,
  sc: 每一站的分數, ck: 碰過這道菜的廚師 }
```

- `wait`：還沒開始這一站，在等位置或等人。
- `fetch`：有人來拿上一站做好的菜（例如從爐上端去出菜口）。
- `go`：已經有人接，人在走過去（下一站的位置先保留）。
- `work`：人在那一站做（手作的部分）。
- `cook`：自己在煮（爐上、烤箱裡），不需要人站著。
- `ready`：這一站做完了，菜留在原地，等送去下一站。不會壞、不會焦，也不會變差。

一個工作從開始做到被送去下一站，一直占著那一站的一個位置。一批（例如 炒飯 ×3）只占一個位置。

## 畫面：沿用原本的廚房

- 沒有新的格子、按鈕或 HUD。每一站就是原本的位置：爐口、烤箱、咖啡機、冷盤台的砧板、出菜口上的盤位。
- **每一站畫什麼**，從那道菜原本的食譜讀出來（`wfLook`）：
  - 備料：如果那道菜在下鍋前本來就有刀工（鴨胸劃刀、舒芙蕾打蛋白、切蔬菜、切菜、開生蠔、捏可樂餅），就是原本的砧板和刀工；
    沒有的話，是那道菜自己的容器，食材一樣一樣放上去；要下鍋的菜（漢堡、牛排、海鮮麵）放在盤子上備好。
  - 熱區：原本的鍋，手在鍋上的時候食材一樣一樣下鍋，炒的時候會拋鍋、煮的時候冒煙，熟度跟著進度變；牛排、鴨胸、漢堡、招牌主菜
    在一半的時候翻面（原本的翻面動作），翻過來是煎好的那一面。
  - 烤箱、披薩烤爐：放進去以後在烤箱裡，原本的烤色跟著進度變。
  - 飲料：在咖啡機下，倒奶、倒氣泡水是原本的倒入畫面。
  - 舊版用量表倒的東西（披薩的醬、布丁液、焦糖、鮮奶油、乳酪糊、奶油、橙醬、高湯、辣醬、油……）：輪到它的時候，畫面上是原本
    倒入的那一道（從上面倒下來、慢慢鋪開），停在舊量表「剛剛好」的量。玩家不用按，Jill 或廚師的手在做（「玩家少按 ≠ Jill 少做」）。
    （2026-10-08 補上：之前新廚房漏畫了這些，披薩備料時看不到醬。）
  - 備料只放「下鍋或進烤箱之前」的食材；鍋裡才加的（例如牛排的奶油）在熱區才出現。
  - 起司拼盤：原本的遊戲（rc8.8 也是）在冷盤台上什麼都沒畫（它的容器「木板」沒有畫法）；現在畫一塊有把手的木板，上面是起司、
    生火腿、無花果、蜂蜜。
  - 裝盤：出菜口的盤位上，原本的料理圖，做完的瞬間撒上原本的最後裝飾。
- 一批會在鍋旁邊小小寫 ×2、×3。
- Jill 會走到她被派去的位置做事（規格：「Jill 自己走過去」）；廚師也一樣。

## 玩家怎麼操作、怎麼知道下一步（引導）

使用者 2026-10-08 的核心句：「點你想做的菜，廚房告訴你去哪；點那個地方，Jill 就開始。」

- 訂單條上每道菜下面有一行小標記，例如 `熱›裝`，現在在哪一站用粗體。
- **誰在做**（使用者：「Ticket 上一個簡單的 handler 名稱就夠」）：有人接手的菜，左上角一個小名字——廚師的短名（阿德、Marco、
  小林）或 Jill（她自己的顏色）；走過去的路上是空心的，開始做了是實心的。等人接的菜沒有名字。
- 點訂單上的菜：選中它，畫面切到廚房，下面出現一張小卡，回答使用者的四件事——這是什麼（菜名，一批寫 ×3）、做到哪（✓ 做完的、
  ● 現在、○ 還沒）、下一步去哪、誰會處理：
  - 還沒開始：「第一步：備料 · 等待處理」
  - 做完一站、等下一站：「下一步：熱區 · 等待處理」
  - 有人決定接手、還在走過去：「下一步：熱區 · 阿德師傅前往中」（真的開始之前就看得到，不會突然被拿走）
  - 開始做：「● 熱區 · 阿德師傅」或「● 熱區 · Jill」
  - 在爐上／烤箱裡自己熟：「● 熱區 · 正在煮」「● 烤箱 · 正在烤」
  - 下一站滿了：「下一步：熱區 · 等空位」，位置只淡淡地亮，不會有錯誤、紅字或警告
- **廚房裡**：一次只有一個強的提示（使用者：「一次只需要一個強 guidance」）——最合理的那個空位置（離菜最近的）亮著、慢慢呼吸，
  一條虛線箭頭指過去；其他也能去的空位置只有很淡的外框。還沒開始的菜，第一站那個位置上會淡淡地放著它「準備開始」的樣子
  （牛排在砧板的盤子上、炒飯的蛋和飯在爐口的鍋裡），沒有字。
- 點亮起來的位置：Jill 走過去做（不用確認、沒有開始鍵）。沒有選菜的時候，直接點一個空的位置，Jill 會接等最久、下一步是那裡的菜。
- **選菜不等於接手**（使用者 §E）：點菜只是看；只有點廚房裡的位置才是派 Jill。
- **拿回來**（使用者 §D）：卡片寫「阿德師傅前往中」的時候，點他要去的那個位置（淡淡亮著的那個）：Jill 接手，阿德放手去找別的工作；
  不跳視窗、不懲罰、菜不重來。他已經開始做了，就讓他做完這一站，Jill 可以接下一站；這時點他的位置只會選中那道菜、看到「● 熱區 · 阿德師傅」。
- 交接只在兩站之間（使用者 §C）：一站一個人，站與站之間誰接都可以。
- 員工已經接手的菜一樣點得到：卡片寫誰在做，他用的那個位置被圈起來。
- **大訂單不縮小**（使用者 §1）：以前一張單超過 5 道菜，按鈕會縮到 28、22 像素；現在一律維持原本的大小，同一道菜、同一個狀態
  （同一批）疊成一個按鈕，旁邊寫 ×2、×3；放不下就像以前一樣橫向捲動（右邊的 › +N）。5 道以內的單跟以前一樣一道一個按鈕。
- 做好的菜在原地等，旁邊一個小小的 ✓；等多久都不會壞、不會焦、分數不會掉。
- 沒有計時器、百分比、分數；有經驗的玩家也一樣看得到這些（不會關掉）。
- 第一天的教學三句改成新的做法（點訂單上的炒飯 → 點亮起來的爐口 → 好了點出菜口）。

## 廚師（M7）

派工（`wfStaff`）每 0.2 秒看一次：每位有空的廚師，跟每個等人接的步驟配對打分（專長 × 100＋等了多久＋本來就排在那一站的加一點），
